Operations

Mail goes to the owner. Acceptance does not confirm inbox receipt. This interface cannot change the site, catalogue, schema or deployment.

Database queries

Read-only results, at most 100 rows per page. Dates filter Submissions and Authentication audit; boundaries are UTC and the end is exclusive. Record class filters Submissions. Profile identifiers filter Profiles, Submissions and Notifications.

Authentication audit shows stored Auth events only; an empty result does not confirm logging is enabled. Security health reports selected operational faults and monitoring freshness. Platform changes, database statement audit and complete runtime errors are separate sources.

Maintenance policy

Production changes originate in GitHub. The native Supabase integration applies backend releases and GitHub Pages publishes the website. This interface has no release credentials or mutation controls.
